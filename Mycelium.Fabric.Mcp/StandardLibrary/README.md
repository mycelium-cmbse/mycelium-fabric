# SysML v2 standard library

The XMI files of the standard library of the OMG SysML v2 release of August 2026 (`sysml.library.xmi` of
https://github.com/Systems-Modeling/SysML-v2-Release : KerML libraries 1.1.0-dev.20260801, SysML libraries
2.1.0-dev.20260801), unchanged. They are licensed under the Eclipse Public License 2.0 (see `LICENSE`).

The MCP server loads them read-only with the `ModelLibraryLoader` of SysML2.NET. The `.kpar` files of the release hold
the textual notation, which SysML2.NET cannot read yet.
